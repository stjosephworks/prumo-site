# Development log

History, kept for context. **Nothing here is referenced by the README, by `content/documents.json` or by
any page, and nothing here is maintained.**

These files recorded the website while it was being built, one decision at a time: why it is a `site`
project generated by Prumo, why it fetches documents instead of copying them, why it has two languages.

| File | Held |
|---|---|
| [`DECISIONS.md`](DECISIONS.md) | 13 entries: the options weighed, why one won, what it cost |
| [`OPEN-QUESTIONS.md`](OPEN-QUESTIONS.md) | What was still unresolved when the log was closed: dark mode, stale pins, the shape of search |

Read them to understand *why* something is the way it is. Do not treat them as current: where one of them
disagrees with the code, the code is right.

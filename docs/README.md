# This site's own documents

These describe **how the website is built**. What it publishes is elsewhere: the pages it writes live in
`src/app/[lang]/`, and the documents it renders live in the repositories `content/documents.json` pins.

| Document | Holds |
|---|---|
| [`DECISIONS.md`](DECISIONS.md) | Every decision taken about the site, newest last: the options weighed, why one won, and what it costs |
| [`OPEN-QUESTIONS.md`](OPEN-QUESTIONS.md) | What has been raised and is still unresolved, each naming what it blocks |

Decisions about Prumo itself belong to
[`prumo`](https://github.com/stjosephworks/prumo/blob/main/docs/DECISIONS.md). This repository depends on
that one; that one does not depend on this.
